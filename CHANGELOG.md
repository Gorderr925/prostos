# История версий ProstOS

Здесь собраны все выпуски проекта. Номер версии в файле `VERSION` определяет,
под каким именем появится следующий релиз.

## 5.0

Возвращение к рабочей основе 3.0 и осторожная доводка «как Mint»: ничего
лишнего, только то, что проверено и не мешает загрузке.

**Брендинг**
- новые обои: тёмно-зелёный градиент, логотип и девиз — сразу в PNG, без
  конвертации при сборке (именно она подводила в 4.0)
- шрифт Inter, иконки Papirus-Dark, тёмные окна Arc-Dark
- фирменные зелёные акценты в кнопках и выделении

**Рабочий стол**
- одна панель снизу, 40 px: меню ProstOS, задачи, лоток, часы, завершение
- убрана вторая (боковая) панель — ближе к Mint
- рабочий стол снова с иконками и обычным меню по правому клику

**Что вернули из 3.0**
- прежний «Центр приложений»: он обновляет списки пакетов и ставит программы,
  а не молча ничего не делает
- прежняя схема запуска установщика (sudo, затем pkexec) — кнопка «Установить»
  снова работает

**Система**
- zstd для squashfs: быстрее распаковка при загрузке
- добавлены Inter, Bluetooth (blueman), настройка принтеров, Vulkan

## 3.0

Обновление по впечатлениям от версии 2.0. Самое большое изменение — знакомство с
системой и забота о новичке.

**Знакомство**
- вместо маленького окошка — полноценный экран приветствия с комплиментом
- две кнопки: «Установить ProstOS» (сразу к разметке диска) и «Хочу попробовать»
- установщик больше не спрашивает то, что уже настроено: приветственный экран
  Calamares убран

**Оформление**
- фирменные обои теперь видны сразу при входе, а не синяя заставка XFCE
- обои в формате PNG — без «поехавшей» картинки на старых видеокартах
- в панели вместо «Приложения» — «ProstOS», вместо «Debian live user» — ProstOS
- значок Debian заменён на фирменный

**Приложения под рукой**
- Wine с автоматическим запуском `.exe` двойным кликом
- Steam и Proton ставятся одним нажатием из «Центра приложений»
- в «Центре приложений»: Telegram, Discord, Chrome, GIMP, OBS, Krita,
  qBittorrent, Audacity, Thunderbird, Lutris
- добавлены калькулятор, блокнот, просмотрщик фото, скриншоты, буфер обмена,
  архиватор 7z, монитор системы

**После установки**
- все иконки «Установить ProstOS» исчезают с рабочего стола и из панели
- при первом входе предлагается установить удобные приложения
- правый клик по рабочему столу: создать папку, текстовый документ, открыть
  терминал здесь, скопировать путь

**Мелочи**
- контекстное меню рабочего стола на русском
- шаблоны документов создаются автоматически

## 2.0

Обновление по итогам тестирования версии 1.0.

**Внешний вид**
- новые фирменные обои: тёмно-зелёные, с логотипом и девизом «Просто. Открыто. Твоё.»
- собственная панель: меню с поиском и избранным, индикатор раскладки RU/EN
- убрана кнопка «Свернуть все окна» из боковой панели
- значок установщика закреплён в боковой панели

**Первые шаги**
- при входе сразу открывается окно «Добро пожаловать в ProstOS»
- две кнопки: «Установить ProstOS» и «Сначала посмотреть»
- значок установки всегда на рабочем столе — искать по папкам не нужно

**Лёгкость и совместимость**
- образ стал меньше: около 3,0 ГБ вместо 3,07 ГБ
- удалены справка LibreOffice, лишние темы загрузки и документация пакетов
- добавлены прошивки для видеокарт NVIDIA (GT 710 и другие)
- установщик запускается без запроса пароля
- исправлено размещение значков на рабочем столе в русской локали

Проверено на реальном железе: ASUS A68HM-PLUS, Athlon X4 845, NVIDIA GT 710,
загрузка через Ventoy при включённом Secure Boot.

## 1.0

Первый публичный выпуск: Debian 13 + XFCE, русский интерфейс, установщик Calamares.

- работа прямо с флешки: диск и Windows не изменяются до установки
- русский язык и раскладка RU/EN (Alt+Shift)
- Firefox, LibreOffice, VLC, GParted, Synaptic
- фирменное оформление ProstOS
- поддержка Secure Boot
- установка на диск за 10–20 минут
