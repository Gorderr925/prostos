# Частые вопросы и решения

Здесь собраны проблемы, с которыми сталкиваются чаще всего, и простые способы
их решить. Если вашей ситуации нет — напишите в
[Issues](https://github.com/Gorderr925/prostos/issues), и она здесь появится.

---

## Загрузка с флешки

### Компьютер грузится в Windows и не видит флешку

Быстрая загрузка (Fast Boot) в Windows перехватывает загрузку. Два решения:

1. При включении многократно нажимайте клавишу меню загрузки: **F8** (ASUS),
   **F12** (Gigabyte, Lenovo, Dell), **F11** (MSI), **F9** (HP).
2. Если не помогло — отключите Fast Boot в Windows: *Панель управления →
   Электропитание → Действия кнопок питания → Изменить недоступные параметры →
   снять «Включить быстрый запуск»*.

В BIOS также стоит проверить порядок загрузки (Boot → Boot Option #1) и
включённый режим **UEFI**.

### Синий экран «Enroll key» / «Verification failed»

Это Secure Boot. Разрешите ключ Ventoy:

1. *Enroll key from disk* → раздел **VTOYEFI** →
   `ENROLL_THIS_KEY_IN_MOKMANAGER.cer`.
2. *Continue* → *Yes* → перезагрузка.
3. Снова войдите в меню загрузки и выберите флешку.

Если экран появляется снова — в BIOS можно временно отключить Secure Boot
(Security → Secure Boot → Disabled), а после установки включить обратно.

### Чёрный экран после выбора ProstOS

Не подхватился видеодрайвер. В меню Ventoy выберите пункт **failsafe** — он
грузится с базовыми настройками. Если помогло, после установки поставьте
драйвер (см. ниже).

### «No bootable device» / флешка не определяется

- Проверьте, что флешка вставлена до включения.
- Попробуйте другой USB-порт, желательно USB 2.0 (чёрный, не синий).
- Перезапишите флешку: возможно, образ скопировался не полностью. Сверьте
  контрольную сумму по `SHA256SUMS.txt`.

## Железо

### Не видит Wi-Fi

Скорее всего, не хватает прошивки для адаптера. Подключитесь кабелем или
телефоном по USB (режим модема) и выполните:

```bash
sudo apt update
sudo apt install -y firmware-iwlwifi firmware-realtek firmware-atheros firmware-brcm80211
sudo reboot
```

Узнать модель адаптера:

```bash
lspci | grep -i network
```

### Нет звука

1. Правый клик по значку динамика → **Настройки звука**.
2. Вкладка **Устройства вывода** — выберите «Аналоговые стерео» или
   «Встроенное аудио», а не S/PDIF.
3. Проверьте, не выключен ли звук на самой клавиатуре (Fn+F-клавиши).

Если в списке вообще нет устройств:

```bash
sudo apt install -y firmware-sof-signed firmware-intel-sound
sudo reboot
```

### Тормозит видео, дёргается картинка

Поставьте проприетарный драйвер NVIDIA (для карт NVIDIA):

```bash
sudo apt install -y nvidia-driver
sudo reboot
```

Для AMD и Intel отдельный драйвер не нужен — всё уже в ядре.

### Не работает Bluetooth

```bash
sudo apt install -y bluetooth blueman
sudo systemctl enable --now bluetooth
```

Затем меню → **Bluetooth-менеджер**.

## Система и программы

### Как узнать версию ProstOS

```bash
cat /etc/prostos-release
```

Или посмотрите на обои — там указана версия.

### Как установить программу, которой нет в менеджере
Три способа, от простого к сложному:

1. **Из репозитория** (безопасно): `sudo apt install имя-пакета`.
2. **Файл `.deb`** (как `.exe` в Windows): скачайте и откройте двойным кликом,
   либо `sudo apt install ./файл.deb`.
3. **Flatpak** (песочница, много свежих программ):
   ```bash
   sudo apt install -y flatpak
   flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
   flatpak install flathub org.telegram.desktop
   ```

> Не скачивайте `.deb` со случайных сайтов — это главный способ поймать
> вредоносное ПО в Linux.

### Как запустить программу для Windows (`.exe`)

Просто дважды щёлкните по файлу — откроется Wine и запустит программу. Первый
запуск может быть медленным (создаётся окружение), это нормально.

Если ничего не происходит:

```bash
wine ~/Загрузки/программа.exe
```

Ошибки Wine читаются по тексту в терминале — скопируйте их в поиск. Для игр
лучше не запускать `.exe` напрямую, а добавить игру в Steam и включить Proton
(Центр приложений → Steam).

### Кончилось место на диске

```bash
df -h                 # сколько свободно
sudo apt clean        # очистить кэш пакетов
sudo apt autoremove   # удалить ненужные зависимости
```

Ещё место съедают старые ядра и корзина. Проверить размер папок:

```bash
du -sh ~/* 2>/dev/null | sort -h
```

### Забыл пароль пользователя

1. При загрузке в меню GRUB нажмите **e** на строке ProstOS.
2. Найдите строку, начинающуюся с `linux`, и допишите в конец `init=/bin/bash`.
3. **Ctrl+X** — загрузится консоль. Выполните:
   ```bash
   mount -o remount,rw /
   passwd имя_пользователя
   reboot -f
   ```

### Система не загружается после обновления

В меню GRUB выберите **Дополнительные параметры → предыдущее ядро**. Система
загрузится со старой версией ядра, и вы сможете спокойно починить обновление.

## Обновления ProstOS

### Как перейти на новую версию

Новая версия ProstOS — это новый образ. Два варианта:

- **Чистая установка** (рекомендуется): сохраните файлы на внешний диск,
  установите новую версию, верните файлы.
- **Сохранение данных:** при установке выберите ручную разметку и оставьте
  раздел `/home` без форматирования — все файлы и настройки останутся.

Следить за выпусками удобно в разделе
[**Releases**](https://github.com/Gorderr925/prostos/releases): каждая версия
получает свой номер, например 3.0 после 2.0.

### Нужно ли переустанавливать систему ради обновлений безопасности

Нет. Обновления безопасности приходят обычной командой:

```bash
sudo apt update && sudo apt full-upgrade -y
```

Новая версия ProstOS — это про удобство и новые возможности, а не про дыры в
безопасности.

## Windows и двойная загрузка

### Как вернуться в Windows

Если ставили «рядом с Windows» — при включении в меню загрузки выберите
**Windows Boot Manager**.

Если меню не появляется, а сразу грузится ProstOS:

```bash
sudo update-grub
```

### Windows не видит файлы из Linux

Так и должно быть: Windows не читает разделы Linux. Обратно — Linux читает
разделы Windows. Для общего доступа используйте флешку с **exFAT** или
облако.

### Хочу удалить ProstOS и оставить Windows

1. Загрузитесь в Windows.
2. *Управление дисками* → удалите разделы Linux (обычно ext4, без буквы диска).
3. Восстановите загрузчик Windows с установочной флешки Windows:
   *Восстановление системы → Командная строка → `bootrec /fixmbr` и
   `bootrec /rebuildbcd`*.
