# Шпаргалка по командам

Держите этот файл под рукой. Все команды вводятся в терминале
(**Ctrl+Alt+T**), вставляются через **Ctrl+Shift+V** (не Ctrl+V — это важная
мелочь, которая экономит нервы).

## Каждый день

| Задача | Команда |
|---|---|
| Обновить список программ | `sudo apt update` |
| Обновить систему | `sudo apt full-upgrade -y` |
| Установить программу | `sudo apt install имя` |
| Удалить программу | `sudo apt remove имя` |
| Найти программу | `apt search слово` |
| Сколько места свободно | `df -h` |
| Где я сейчас | `pwd` |
| Что в папке | `ls -l` |
| Перейти в папку | `cd /путь/к/папке` |
| Домой | `cd ~` |
| На уровень выше | `cd ..` |

## Файлы и папки

| Задача | Команда |
|---|---|
| Создать папку | `mkdir имя` |
| Скопировать | `cp файл /куда/` |
| Скопировать папку | `cp -r папка /куда/` |
| Переместить или переименовать | `mv файл новое_имя` |
| Удалить файл | `rm файл` |
| Удалить папку с содержимым | `rm -rf папка` |
| Размер папок | `du -sh *` |
| Права на запись | `sudo chown -R $USER:$USER файл` |

> ⚠️ `sudo rm -rf` не спрашивает подтверждения и не отправляет файлы в корзину.
> Проверяйте путь дважды, особенно если в нём есть пробелы или звёздочки.

## Система

| Задача | Команда |
|---|---|
| Версия системы | `cat /etc/prostos-release` |
| Версия ядра | `uname -r` |
| Модель видеокарты | `lspci -k \| grep -A3 -i vga` |
| Температура процессора | `sensors` (пакет `lm-sensors`) |
| Занятость памяти | `free -h` |
| Что грузит процессор | `top` (выход — `q`) |
| Службы | `systemctl status имя` |
| Перезагрузить | `sudo reboot` |
| Выключить | `sudo poweroff` |

## Сеть

| Задача | Команда |
|---|---|
| IP-адрес | `ip a` |
| Проверить интернет | `ping -c 4 ya.ru` |
| Список Wi-Fi сетей | `nmcli device wifi list` |
| Подключиться к Wi-Fi | `nmcli device wifi connect "Имя" password "пароль"` |
| Открытые порты | `ss -tulpn` |

## Диски и флешки

| Задача | Команда |
|---|---|
| Список дисков | `lsblk -o NAME,SIZE,FSTYPE,LABEL,MOUNTPOINT` |
| Подробно о разделах | `sudo fdisk -l` |
| Смонтировать флешку | `sudo mount /dev/sdb1 /mnt` |
| Размонтировать | `sudo umount /mnt` |
| Проверить файловую систему | `sudo fsck /dev/sdb1` |

> Имена дисков (`sda`, `sdb`) легко перепутать. Перед командами с `dd` или
> `mkfs` трижды проверьте, что это не ваш системный диск.

## Полезные мелочи

```bash
history                    # история команд
history | grep apt         # что я устанавливал
!!                         # повторить последнюю команду
sudo !!                    # повторить с правами администратора
команда | less             # длинный вывод постранично (выход — q)
команда > файл.txt         # записать вывод в файл
команда --help             # краткая справка
man команда                # полное руководство (выход — q)
```

## Если что-то сломалось

```bash
sudo apt update                                   # обновить список
sudo apt install -f                               # починить зависимости
sudo dpkg --configure -a                          # дособрать пакеты
journalctl -p 3 -xb                               # ошибки текущей загрузки
journalctl -xe                                    # подробный журнал
```

Не паникуйте: почти любая ошибка в Linux уже кем-то встречена, и текст ошибки
можно просто скопировать в поиск.
