# Первые шаги после установки

Пять минут настройки — и система будет вашей. Всё делается мышкой, терминал
понадобится только для обновлений и драйверов (и там будет готовая команда для
копирования).

## 1. Подключить интернет

**Wi-Fi.** Значок сети справа вверху → выберите сеть → введите пароль.
Если сеть не появилась — возможно, не хватает прошивки для вашего адаптера:
смотрите [ЧАСТЫЕ-ВОПРОСЫ.md](FAQ.md), раздел «Не видит Wi-Fi».

**Кабель.** Обычно работает сразу, ничего настраивать не нужно.

## 2. Обновить систему

Откройте терминал: меню → **Терминал** (или **Ctrl+Alt+T**). Вставьте команду
целиком и нажмите Enter. Пароль при вводе не отображается — это нормально,
просто печатайте и жмите Enter.

```bash
sudo apt update && sudo apt full-upgrade -y
```

Затем перезагрузитесь. Делать это стоит раз в месяц, а не каждый день.

## 3. Проверить раскладку и часы

- Раскладка переключается **Alt+Shift**. Текущая видна в панели справа.
- Часы: правый клик по времени → **Свойства** → формат.
- Часовой пояс: меню → **Настройки** → **Дата и время**.

## 4. Видеокарта NVIDIA (только если она у вас есть)

В системе уже есть открытый драйвер **nouveau** и прошивки для карт NVIDIA —
картинка будет работать сразу. Проприетарный драйвер даёт больше
производительности в играх и 3D:

```bash
sudo apt install -y nvidia-driver firmware-misc-nonfree
```

После установки — перезагрузка. Проверить, что драйвер работает:

```bash
nvidia-smi
```

> Если после установки драйвера экран стал чёрным — загрузитесь в
> дополнительном режиме, удалите пакет `nvidia-driver` и вернитесь на nouveau.
> Для офисной работы разницы вы не заметите.

## 5. Установить нужные программы

Всё ставится одной командой в терминале:

```bash
sudo apt install -y telegram-desktop gimp inkscape audacity
```

Популярные замены привычных программ:

| В Windows | В ProstOS | Команда |
|---|---|---|
| Word / Excel | LibreOffice | уже установлен |
| Photoshop | GIMP | `sudo apt install gimp` |
| Skype / Discord | Telegram, Element | `sudo apt install telegram-desktop` |
| WinRAR | File Roller | уже установлен |
| Notepad++ | Mousepad | `sudo apt install mousepad` |
| Paint | Drawing | `sudo apt install drawing` |
| Проводник | Thunar | уже установлен |
| Калькулятор | Galculator | `sudo apt install galculator` |

Искать программы удобнее всего в меню: нажмите кнопку **ProstOS** слева вверху
и начните печатать название.

## 6. Звук и Bluetooth

- **Звук:** значок динамика справа вверху. Если звука нет — проверьте, не
  выбран ли выход «Цифровой» (S/PDIF) вместо колонок.
- **Bluetooth:** значок в трее → включите адаптер → «Добавить устройство».
  Если значка нет: `sudo apt install bluetooth blueman`, затем
  меню → **Bluetooth-менеджер**.

## 7. Принтер

Меню → **Настройки** → **Принтеры** → **Добавить**. Большинство современных
принтеров находятся в сети автоматически. Для старых может понадобиться пакет:

```bash
sudo apt install -y printer-driver-all
```

## 8. Горячие клавиши, которые стоит запомнить

| Клавиши | Что делают |
|---|---|
| **Alt+Shift** | переключить раскладку RU/EN |
| **Ctrl+Alt+T** | открыть терминал |
| **Alt+F2** | выполнить команду |
| **Super** (клавиша Windows) | меню приложений с поиском |
| **Print Screen** | снимок экрана |
| **Ctrl+Alt+Delete** | выход, блокировка, перезагрузка |
| **Alt+Tab** | переключение между окнами |

Полный список: **Настройки → Клавиатура → Комбинации клавиш**. Там же любое
сочетание можно поменять под себя.

## 9. Внешний вид под себя

- **Обои:** правый клик по рабочему столу → **Параметры рабочего стола**.
- **Тема и иконки:** меню → **Настройки** → **Внешний вид**.
- **Панель:** правый клик по панели → **Панель** → **Настройки панели**. Можно
  добавить или убрать значки, изменить размер, включить автоскрытие.
