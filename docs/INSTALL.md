# Установка ProstOS на компьютер

Инструкция для человека, который делает это впервые. Ничего страшного не
случится: пока вы не нажмёте «Установить», система работает только с флешки и
ваш диск не трогает.

## Что понадобится

| Что | Сколько |
|---|---|
| Флешка | 8 ГБ и больше (образ весит ~3 ГБ) |
| Время | 15 минут на запись флешки, 10–20 минут на установку |
| Интернет | желателен, но не обязателен |
| Свободное место на диске | минимум 20 ГБ, комфортно — 40 ГБ |

> ⚠️ Всё, что лежит на флешке, при записи образа будет стёрто. Освободите её
> заранее.

## Шаг 1. Записать образ на флешку

### Вариант А — Ventoy (рекомендую)

Удобен тем, что образ просто копируется файлом: на флешке можно держать сразу
несколько версий ProstOS и выбирать нужную при загрузке.

1. Скачайте Ventoy с [ventoy.net](https://www.ventoy.net) и запустите
   `Ventoy2Disk.exe`.
2. Выберите флешку → **Установить** → подтвердите (данные на флешке сотрутся).
3. Скопируйте на флешку готовый файл `ProstOS-2.0.iso` (целиком, не распаковывая).
4. Если образ скачан частями (`prostos.iso.part00`, `part01`, …) — сначала
   склейте их. В Windows откройте папку с частями, зажмите Shift, щёлкните
   правой кнопкой → «Открыть окно PowerShell» и выполните:

   ```powershell
   cmd /c copy /b prostos.iso.part* prostos.iso
   ```

### Вариант Б — Rufus

1. Скачайте [Rufus](https://rufus.ie).
2. Устройство → ваша флешка. Нажмите **Выбрать** и укажите ISO.
3. Схема раздела — **GPT**, целевая система — **UEFI**.
4. **Старт** → согласитесь на стирание данных.

## Шаг 2. Загрузиться с флешки

1. Вставьте флешку и перезагрузите компьютер.
2. Сразу после включения многократно нажимайте клавишу меню загрузки:
   - ASUS — **F8**
   - Gigabyte — **F12**
   - MSI — **F11**
   - Lenovo — **F12**
   - HP — **F9**
   - Dell — **F12**
3. Выберите пункт, где есть слово **UEFI** и название вашей флешки
   (например, `UEFI: General UDisk`).
4. В меню Ventoy выберите `ProstOS-2.0.iso` → первый пункт.

**Если появился синий экран «Enroll key»** — это Secure Boot просит разрешение
на загрузку. Нажмите *Enroll key from disk* → выберите раздел **VTOYEFI** →
файл `ENROLL_THIS_KEY_IN_MOKMANAGER.cer` → *Continue* → *Yes* → перезагрузитесь
и повторите шаг 2.

**Если экран чёрный и ничего не происходит** — при загрузке выберите пункт
**failsafe** (безопасный режим).

## Шаг 3. Посмотреть систему

Через несколько секунд появится рабочий стол и окно «Добро пожаловать в
ProstOS». Нажмите **«Сначала посмотреть»**, если хотите просто попробовать:

- подключите Wi-Fi (значок сети справа вверху);
- откройте браузер, проверьте видео и звук;
- переключите раскладку — **Alt+Shift**.

Ваш диск в этот момент не изменён. Всё, что вы сделали, исчезнет после
перезагрузки — это нормально.

## Шаг 4. Установить на диск

1. Нажмите значок **«Установить ProstOS»** на рабочем столе (или в боковой
   панели).
2. **Язык** — Русский.
3. **Клавиатура** — Russian (раскладка будет RU/EN).
4. **Часовой пояс** — ваш город (по умолчанию Москва).
5. **Разметка диска** — самый важный шаг:
   - **«Стереть диск»** — весь диск будет очищен, Windows исчезнет.
     Выбирайте, если компьютер целиком ваш.
   - **«Установить рядом с Windows»** — сохранит Windows и даст выбор при
     загрузке. Выбирайте, если не уверены.
   - **«Ручная разметка»** — для тех, кто знает, что делает.
6. **Пользователь**: имя, имя компьютера, пароль. Пароль запомните — он нужен
   для установки программ и обновлений.
7. **Установить** → подождите 10–20 минут.

## Шаг 5. Первая загрузка

1. Когда установщик предложит перезагрузку — выключите компьютер, выньте
   флешку и включите снова.
2. Если ставили рядом с Windows — при загрузке появится меню, где можно выбрать
   **ProstOS** или **Windows**.
3. Войдите под своим пользователем и паролем.

Дальше смотрите [ПЕРВЫЕ-ШАГИ.md](FIRST-STEPS.md) — что настроить в первую
очередь.

## Как вернуться в Windows

- Если ставили **рядом с Windows**: в меню загрузки выберите Windows.
- Если стёрли диск: Windows больше нет. Данные можно было сохранить заранее —
  это единственный необратимый шаг во всей инструкции. Поэтому на всякий случай
  сделайте копию важных файлов на внешний диск до установки.
